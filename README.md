# Dijital Elifba Geliştirme Çalışma Alanı

Bu dizin, ses denetimli çocuk Elifba projesinin başlangıç kodlarını ve müfredat verilerini içerir.

## Dizin Yapısı

* `data/curriculum.json`: Kitapçık sayfalarındaki harfler, harekeler, mahreç bilgileri ve çocuklara yönelik yönlendirici ipuçları.
* `engine/evaluator.py`: Akustik skora ve hata türüne göre dinamik, pedagojik çocuk geri bildirimi üreten motor.

## Test Etmek İçin

```bash
python3 engine/evaluator.py
```
